# Digital Payment Insight

## Project Overview
This project analyses digital payment transactions to identify unusual patterns and support data-driven decisions.

## Tools Used
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Microsoft Excel

## Project Files
- Google Colab notebook: Data preprocessing, EDA and feature engineering.
- Excel workbook: Analysis, PivotTables and visualization dashboard.

## Conclusion
The project helps identify unusual transaction patterns and supports further investigation and better monitoring decisions.
